# だいべんしゃ 🔍

> AI への質問を深掘りして、あなただけの答えを引き出す

「ChatGPT に聞いたけど、なんか的外れ」——それは質問が浅いからではなく、  
AI があなたの状況を知らないまま答えているからです。

だいべんしゃは、**5W2H に基づいた問い返し**で質問を深掘りし、  
一般論ではなくあなたの状況・環境に合わせた回答を引き出します。

## 主な機能

- 🤔 **質問の深掘り** — 入力した質問を 5W2H で分解し、足りない情報を問い返す
- 🎯 **状況特化の回答** — あなたの環境・条件を把握した上で AI が答える
- 🔄 **対話型ブラッシュアップ** — やり取りを重ねるほど精度が上がる

## 技術スタック

| 項目 | 内容 |
|---|---|
| フレームワーク | Next.js |
| 言語 | TypeScript |
| スタイリング | Tailwind CSS |
| AI エンジン | Claude API (Anthropic) |
| デプロイ | Vercel |

## ローカル起動

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) で確認。
